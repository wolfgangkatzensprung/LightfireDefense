# LightfireDefense

![LightFireDefense_Title_Headerkapsel](https://github.com/user-attachments/assets/323e4b88-297b-4115-a9b7-c776f8e0bd2d)

This a 3D First Person Tower Defense/Platformer Crossgenre Game that was made with Unity and has been in development from 2019 until it was released on Steam at August 12th 2022. Afterwards it was updated with new features and fixes until February 2023.The project is now discontinued.

My intention was to make a game where I create every single asset of the game by hand, including (of course) the code, but also all models, sounds, music, vfx, shaders, textures, etc. Though, there were some exceptions to this rule (see below).

It features many basic custom solutions for common problems, such as
- classic tower defense mechanics
- various ways of physics-based enemy movement
- combat systems using damage types & dynamic spell effects
- player progression / upgrades / items
- audio pooling and crossfades
- scene management and data persistence
- editor utility

To me, this project was both a playground for experimenting with different ideas and concepts, as well as a challenge to refine my game development skills across all areas, while receiving feedback from family, friends, players and other game developers who tested the game.

## Dependencies
To be able to start the Unity project without errors, the following external assets are required:
- [Easy Character Movement](https://assetstore.unity.com/packages/templates/systems/easy-character-movement-57985)
- [Sky Series Freebie](https://assetstore.unity.com/packages/2d/textures-materials/sky/skybox-series-free-103633)
- [Hovl Studio White Mage Spells](https://assetstore.unity.com/packages/vfx/particles/spells/white-mage-spells-161173)
